This is **[henkhooft/SS3D](https://github.com/henkhooft/SS3D)**, a development fork of
[RE-SS3D/SS3D](https://github.com/RE-SS3D/SS3D) that moves faster than upstream. It runs on Unity 6 + URP
with [FishNet](https://fish-networking.com/) networking and rewritten gameplay systems: interactions, health,
melee combat, inventory, atmos, power, the in-game map editor and more. The full list of differences is in
[FORK_STATUS](Documents/FORK_STATUS.md).

## Play

1. Download the latest **[release](https://github.com/henkhooft/SS3D/releases/latest)**:
   `SS3D-Windows-<version>.zip`, or the Linux client or server zip.
2. Unzip it and run **`Game\SS3D.exe`** (Linux: `Game/SS3D-Client`).
3. From the main menu, **Play locally** to host on your PC (you're admin, so the map editor works), or
   paste a server address and join.

To update, use **Update and restart** in the main menu, or close the game and run `Update_SS3D.bat`
(Linux: `./update_ss3d.sh`). Your maps, config and logs are kept, and the previous install is backed up.
Details: [updater README](Tools/updater/README.md).

New to testing? The **[testers' guide](Builds/TESTERS.md)** covers building a station, saving and sharing
maps, and filing bug reports (press **F8** in game).

## Build from source

```bash
git clone https://github.com/henkhooft/SS3D.git
cd SS3D
git checkout develop
```

Open the folder in Unity Hub with editor **`6000.3.28f1`**. Setup notes are in
[CONTRIBUTING](Documents/CONTRIBUTING.md); tests and validation in [Testing/ui/README.md](Testing/ui/README.md).
