Space Station 3D is an open-source resurrection of
[*beep's original SS3D](https://www.youtube.com/watch?v=VB7ddhayLKA&list=PLTkyYJ6zDmhoiQv5PJYT6oI766G4s60Av), a demo
that gave Space Station 13 an extra dimension. It runs on Unity 6 + URP with [FishNet](https://fish-networking.com/)
networking: interactions, health, combat, inventory, atmospherics, power, an in-game map editor and more.
**[About](https://ss3d.space/about/) · [FAQ](https://ss3d.space/faq/) · [Devblogs](https://ss3d.space/devblog/)**

## Play

1. Download the latest **[release](https://github.com/RE-SS3D/SS3D/releases/latest)**:
   `SS3D-Windows-<version>.zip`, or the Linux client or server zip.
2. Unzip it and run **`Game\SS3D.exe`** (Linux: `Game/SS3D-Client`).
3. From the main menu, **Play locally** to host on your PC (you're admin, so the map editor works), or
   paste a server address and join.

To update, use **Update and restart** in the main menu, or close the game and run `Update_SS3D.bat`
(Linux: `./update_ss3d.sh`). Your maps, config and logs are kept, and the previous install is backed up.
Details: [updater README](Tools/updater/README.md).

New to testing? The **[testers' guide](Builds/TESTERS.md)** covers building a station, saving and sharing
maps, and filing bug reports (press **F8** in game).

## Contribute

SS3D is built docs-first, with AI coding agents. **[CONTRIBUTING.md](CONTRIBUTING.md)** walks through setup and
the loop every change follows. To build from source:

```bash
git clone https://github.com/RE-SS3D/SS3D.git
cd SS3D
git checkout develop
```

Open the folder in Unity Hub with editor **`6000.3.28f1`**. Find your way in through the docs:

| Want… | Go to… |
|---|---|
| What to build next | [Documents/milestones/](Documents/milestones/INDEX.md) |
| Where a system lives in code | [Documents/architecture/INDEX.md](Documents/architecture/INDEX.md) |
| What a system should do, and why | [Documents/design/](Documents/design/) |
| How to write docs here | [Documents/SKILL.md](Documents/SKILL.md) |
| Working with an AI agent | [AGENTS.md](AGENTS.md) |

Bugs go in [issues](https://github.com/RE-SS3D/SS3D/issues); questions and ideas in
[Discussions](https://github.com/RE-SS3D/SS3D/discussions).
