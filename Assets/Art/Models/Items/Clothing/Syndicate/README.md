# Syndicate hardsuit source

FBXs supplied by the owner from `SS3D-Art-main/Pulled from Google Drive`:
`SyndicateHardsuit.fbx` and `HardsuitHelmet.fbx`. The original Blender sources remain
in that source folder. The suit FBX also contains the magboots and the helmet used in game.
`HardsuitHelmet.fbx` is a separate model that nothing uses now: the helmet shows the suit
FBX's mesh when worn, held and on the floor.

Worn and preview hardsuit meshes, worn magboot meshes and the emissive material are generated by
`SyndicateHardsuitSetup`, on Inventory → Run Content Prefab Recipes. Rebuild the
Human equipment wiring through Entities → Run All Human Prefab Recipes after the
content assets exist. Raw skin indices differ from Human: use the generated meshes.

The supplied suit has no body morph blend shapes. Its opaque shell conceals the
underlying body/jumpsuit while equipped. Armor values are provisional.
